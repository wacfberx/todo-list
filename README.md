# Todo List

This is an assignment as part of Code the Dream's React course.

The app is a simple todo list using React and Vite. As of right now, it meets the requirements for the first week assignment, which is to display a tile and a list of todo items. 

## Installation Instructions
1. Clone the repository: 
```bash
    git clone https://github.com/wacfberx/todo-list.git
    cd todo-list
```

2. Install the project dependencies using NPM:
```bash
    npm install
```

## How to run the development server
Vite transforms the code so can be understood by the browser.
You will notice a local url in the Vite CLI that points to `http://localhost:5173/`. This is the port number that Vite serves locally. To view the app, open a browser and navigate to the local url. Changes to your app will be reflected automatically once they are saved. 
```bash
    npm run dev
```
